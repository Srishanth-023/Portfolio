## 🌟 About The Project

This is my personal 3D interactive portfolio designed to bring my resume to life. Built using **React**, **Three.js**, and **Tailwind CSS**, it creates a dynamic, interactive experience for users. 

### 🚀 Built With

* [![React][React.js]][React-url]
* [![Vite][Vite]][Vite-url]
* [![Threejs][Three.js]][Three-url]
* [![TailwindCSS][TailwindCSS]][Tailwind-url]

## 🎯 Features

- **3D Interactive Island**: Drag to rotate an immersive 3D world with momentum-based physics.
- **Dynamic Animations**: Flying birds, responsive biplanes, and an animated fox reacting to user inputs.
- **Responsive Layouts**: Seamless experience across mobile, tablet, and desktop viewports.
- **Dynamic Routing**: Instant page transitions using `react-router-dom`.
- **Contact Integration**: Live, functional contact form hooked up via EmailJS.
