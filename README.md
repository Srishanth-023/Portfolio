## ✨ About The Project

This is my personal 3D interactive portfolio designed to bring my resume and projects to life. Built using **React**, **Three.js**, and **Tailwind CSS**, it establishes a dynamic and interactive experience that showcases my work in AI, full-stack web, and embedded systems.

* [![Vite][Vite]][Vite-url]

## 🎯 Features

- 🏝️ **3D Interactive Island**: Drag to rotate an immersive 3D world with momentum-based physics.
- 🦊 **Dynamic Animations**: Flying birds, responsive biplanes, and an animated fox reacting to user inputs.
- 📱 **Responsive Design**: Seamless experience across mobile, tablet, and desktop viewports.
- ⚡ **High Performance**: Features highly optimized, compressed `.glb` 3D assets (Draco/Meshopt) and native resource fallback boundaries.
- 📬 **Live Contact Form**: Fully functional contact form integration securely hooked up via EmailJS.
